LA NOSTRA IDEA DI PRIVACY

Il tuo ricamo resta tuo.

PuntoPunto nasce per condividere uno strumento utile con chi ama il punto croce. È gratuito, senza scopo commerciale e utilizzabile senza creare un account. Non monetizziamo le tue attività e non raccogliamo dati per profilarti.

01

I tuoi schemi vengono elaborati nel browser

Quando apri uno schema OXS o un PDF, PuntoPunto lo legge ed elabora sul tuo dispositivo. Anche la griglia, le modifiche, la legenda, i punti segnati e la generazione dei file esportati sono gestiti dal browser. L'applicazione non invia i contenuti dei tuoi schemi a un server PuntoPunto.

Il sito non prevede account personali, commenti pubblici, pubblicazione dei progetti o sincronizzazione cloud gestita da PuntoPunto.

02

I salvataggi rimangono sul tuo dispositivo

Per conservare i progressi PuntoPunto usa gli archivi del browser, come IndexedDB e localStorage. Qui possono restare i punti completati, i filati, le impostazioni, le copie di sicurezza e, per i progetti PDF, il documento originale quando previsto dal formato di salvataggio.

Se cancelli i dati del sito, usi la navigazione privata o cambi dispositivo, potresti perdere le copie locali. Per questo consigliamo di esportare e conservare un backup del progetto o dei progressi in un file sul tuo dispositivo.

03

Nessuna profilazione o sfruttamento commerciale

PuntoPunto non integra strumenti di analisi del comportamento degli utenti, pixel di marketing, sistemi pubblicitari o funzioni destinate a tracciare le persone. Non utilizziamo i contenuti dei progetti per addestramento di sistemi automatici, ricerche di mercato o vendita di informazioni.

Il codice dell'applicazione non imposta cookie di profilazione. Eventuali cookie tecnici di una futura protezione d'accesso alla beta, se attivata dall'hosting, devono essere descritti separatamente al momento della pubblicazione.

04

Che cosa cambia quando apri il sito online?

Durante la beta, PuntoPunto è distribuito tramite GitHub Pages, all'indirizzo sandbox1115.github.io/PuntoPunto/. Per distribuire pagine, script e risorse, il browser contatta i server del servizio. Secondo la documentazione di GitHub, l'indirizzo IP di chi visita GitHub Pages viene registrato e conservato per finalità di sicurezza, anche senza accesso a un account GitHub. La gestione dei dati tecnici del servizio è descritta nell'informativa tecnica di GitHub Pages e nella privacy policy di GitHub.

I tuoi PDF, schemi OXS e progressi non sono inviati a GitHub da PuntoPunto: l'elaborazione rimane nel browser. Il gestore dell'hosting può comunque disporre di metadati di rete relativi all'accesso al sito. Non installiamo strumenti nostri di analisi del traffico e non utilizziamo quei dati per profilare i ricamatori.

Le librerie PDF.js e il catalogo DMC sono distribuiti insieme a PuntoPunto e caricati localmente dal sito. Non sono previsti caricamenti automatici di librerie da CDN né richieste a servizi esterni per elaborare PDF o OXS. Se un file necessario manca, la funzione interessata avvisa dell’errore. I collegamenti a pagine di terzi si aprono soltanto quando li scegli.

L’infrastruttura utilizzata è GitHub Pages, fornita da GitHub. I dettagli sulle modalità e sui tempi di conservazione dei log sono disciplinati dal fornitore: PuntoPunto non li controlla né dichiara un periodo di conservazione non verificato. Prima dell’apertura effettiva della beta va completata l’identificazione del titolare/responsabile del progetto e un recapito per le richieste privacy.

05

Il controllo resta a te

Puoi esportare i tuoi file, conservarli dove preferisci ed eliminare le informazioni locali attraverso le impostazioni del browser. Non chiediamo di comunicarci nome, email o abitudini di ricamo per poter usare l'applicazione.

Questa pagina descrive il comportamento del software v0.9.8.8.18, distribuito tramite GitHub Pages. L’indirizzo previsto per il sito fa riferimento all’account GitHub Sandbox1115. L’account non sostituisce l’indicazione formale del titolare del trattamento e di un contatto dedicato, da completare prima della beta online.

06

Feedback e assistenza tramite GitHub Issues

Per segnalare malfunzionamenti o proporre miglioramenti puoi usare GitHub Issues di PuntoPunto, il canale ufficiale per il supporto tecnico durante la beta. Per creare una segnalazione è necessario un account GitHub; il contenuto pubblicato sarà visibile a chiunque.

Non inserire nelle segnalazioni pubbliche nomi, indirizzi email, dati sensibili, PDF riservati, schemi protetti o copie dei tuoi progetti. GitHub gestisce le informazioni associate all'account e alle segnalazioni secondo la propria informativa. Le Issues non sono un canale confidenziale per l'esercizio dei diritti privacy: un recapito privato e l'identificazione formale del titolare devono ancora essere definiti prima della beta.
